# 🗺️ Temporada 3: Mapas con Python

Tus datos sobre un mapa interactivo, con **Folium**. Cada script crea una página web (`.html`) que se abre en tu navegador.

```bash
pip install folium
```

| Episodio | Tema | Carpeta |
| --- | --- | --- |
| 1 | Tu primer mapa: latitud, longitud y zoom | [`episodio-1-primer-mapa`](episodio-1-primer-mapa) |
| 2 | Marcadores y popups: pines con mensaje y un `for` | [`episodio-2-marcadores`](episodio-2-marcadores) |
| 3 | Del Excel al mapa: un pin por cada fila, con su color según las ventas | [`episodio-3-excel-al-mapa`](episodio-3-excel-al-mapa) |
| 4 | Boss final: mapa de calor y capas que se prenden y apagan | [`episodio-4-mapa-de-calor`](episodio-4-mapa-de-calor) |

Cada carpeta trae el código del video, listo para correr, y la misión resuelta.

> 💡 Los mapas usan OpenStreetMap: necesitas internet para ver las calles cuando abres el `.html`.
